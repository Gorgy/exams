# День 10. Финальный набор

## Контрольные задачи перед работой

1. Вычисли: `(3/5 - 1/10) * 4`.
2. Найди число, если `25%` этого числа равны `18`.
3. Упрости: `2x + 5 - (x - 3)`.
4. Упрости: `(a + 2)(a - 2)`.
5. Реши уравнение: `4x + 9 = 29`.
6. Реши уравнение: `3(x - 1) = 2x + 7`.
7. Найди значение функции `y = -2x + 5`, если `x = -3`.
8. Для функции `y = x + 6` найди `x`, если `y = 2`.
9. Один из смежных углов на `30°` меньше другого. Найди оба угла.
10. В треугольнике два угла равны `61°` и `49°`. Найди третий.
11. В равнобедренном треугольнике угол при вершине равен `20°`. Найди углы при основании.
12. Периметр равнобедренного треугольника `38` см, боковая сторона `11` см. Найди основание.
13. Один из односторонних углов равен `118°`. Найди другой.
14. Биссектриса делит угол `94°`. Найди образовавшиеся углы.
15. Найди значение выражения `25m - 9n + 4`, если `m = 2`, `n = 5`.
16. Реши задачу на движение: пешеход шел `4` часа со скоростью `6` км/ч. Какой путь он прошел?
17. Из двух городов одновременно навстречу друг другу выехали велосипедист и мотоциклист со скоростями `14` км/ч и `46` км/ч. Через сколько часов они встретятся, если между городами `180` км?
18. В треугольнике `ABC` `AB = AC`, `∠B = 53°`. Найди `∠A`.
19. Докажи: в равнобедренном треугольнике углы при основании равны.
20. Составь полное решение задачи: на продолжениях боковых сторон равнобедренного треугольника отмечены точки, а соединяющий их отрезок параллелен основанию. Докажи равенство получившихся внешних отрезков.
