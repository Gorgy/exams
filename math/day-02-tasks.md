# День 2. Задачи

## Алгебраические выражения и преобразования

1. Вычисли: `(8^4 * 8^5) / 8^2`.
2. Вычисли: `(3^5 * 3^2) / 3^4`.
3. Приведи к стандартному виду одночлен: `(1/3)c^2d^6 * 12c^3d`.
4. Приведи к стандартному виду одночлен: `-2a^3b * 5ab^2`.
5. Упрости: `5a - 3a + 7`.
6. Упрости: `4x - 2 + 3x + 8`.
7. Раскрой скобки: `3(x - 4)`.
8. Раскрой скобки: `-2(5y + 1)`.
9. Упрости: `2(a + 3) - 4a`.
10. Упрости: `3(2x - 1) - (x + 5)`.
11. Выполни умножение: `x(x + 7)`.
12. Выполни умножение: `3a(2a - 5)`.
13. Выполни умножение: `(x + 2)(x + 5)`.
14. Выполни умножение: `(a - 4)(a + 1)`.
15. Применяя формулу, раскрой: `(2a - 3)^2`.
16. Применяя формулу, раскрой: `(x + 3)^2`.
17. Разложи на множители: `36m^5n^6 + 28m^8n^6`.
18. Разложи на множители: `5a^2 - 10a`.
19. Найди значение выражения `2a^2 - 3a + 4`, если `a = -2`.
20. Представь в виде многочлена: `(x - 3)(x - 3)`.
