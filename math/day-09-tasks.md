# День 9. Пробная работа

## Смешанный набор из 20 задач

1. Вычисли: `7/12 + 5/18`.
2. Найди `35%` от числа `240`.
3. Реши уравнение: `3x - 7 = 20`.
4. Упрости: `4(a - 2) + 3a`.
5. Найди значение выражения `x^2 - 2x + 5`, если `x = 3`.
6. Для функции `y = 2x - 1` найди `y`, если `x = 6`.
7. Определи по функции `y = -3x + 2`, возрастает она или убывает.
8. Один из смежных углов равен `132°`. Найди второй.
9. В треугольнике два угла равны `48°` и `67°`. Найди третий.
10. Периметр равнобедренного треугольника `44` см, основание `12` см. Найди боковую сторону.
11. Биссектриса делит угол `86°`. Найди получившиеся углы.
12. Один из внутренних накрест лежащих углов равен `59°`. Найди второй.
13. Найди значение выражения `18a - 7b + 9`, если `a = 2`, `b = -1`.
14. Реши уравнение: `2(3x + 1) = 5x + 9`.
15. Из двух пунктов навстречу друг другу выехали автомобили со скоростями `70` км/ч и `80` км/ч. Через сколько часов они встретятся, если расстояние `450` км?
16. В треугольнике `ABC` `AB = AC`, угол при вершине равен `44°`. Найди углы при основании.
17. Докажи: если в треугольнике два угла равны, то против них лежат равные стороны.
18. Внешний угол треугольника равен `125°`, один удаленный внутренний угол `48°`. Найди второй.
19. На диаграмме `55%` учеников выбрали английский, `25%` немецкий, `20%` французский. Какой язык выбрало большинство?
20. Составь уравнение и реши: число увеличили на `14`, затем получили `39`.
