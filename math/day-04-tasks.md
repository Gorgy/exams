# День 4. Задачи

## Координаты, графики и диаграммы

1. Отметь на координатной прямой точки с координатами `-3`, `1,5`, `4`.
2. Какая из точек лежит левее: `A(-2)` или `B(1,5)`?
3. Запиши координаты точки, расположенной посередине между `2` и `8`.
4. Отметь в координатной плоскости точки `A(2; 3)` и `B(-1; 4)`.
5. В какой четверти находится точка `M(-3; -2)`?
6. В какой четверти находится точка `N(4; -5)`?
7. Построй график функции `y = 2x`.
8. Построй график функции `y = -x + 3`.
9. Найди значение функции `y = 3x - 2`, если `x = 4`.
10. Найди значение аргумента, если в функции `y = 5x + 1` значение `y = 16`.
11. Определи, возрастает или убывает функция `y = -4x + 7`.
12. Определи, проходит ли график функции `y = 2x + 1` через точку `(3; 7)`.
13. Составь таблицу значений для функции `y = x - 2` при `x = -1, 0, 2, 5`.
14. Построй график функции `y = -3x + 3`.
15. Пользуясь графиком функции `y = -3x + 3`, укажи, при каких значениях `x` функция принимает положительные значения.
16. На графике показана зависимость пути от времени. Объясни, что означает увеличение графика вверх.
17. На диаграмме три сектора: `30%`, `45%`, `25%`. Какой сектор самый большой?
18. В таблице указаны температуры по дням: `18`, `20`, `17`, `21`, `19`. Найди среднее значение.
19. По диаграмме известно, что `40%` учеников выбрали футбол, `35%` плавание, `25%` шахматы. Какой вид занятия выбрало меньше всего учеников?
20. Построй график функции `y = |x|` для `x = -3, -2, -1, 0, 1, 2, 3`.
