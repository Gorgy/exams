# День 5. Задачи

## Углы и равнобедренный треугольник

1. Определи, в каком случае точки `A`, `B`, `C` лежат на одной прямой: `AB = 14`, `AC = 7`, `BC = 21`.
2. Определи, в каком случае точки `A`, `B`, `C` лежат на одной прямой: `AB = 6`, `AC = 14`, `BC = 9`.
3. Один из смежных углов равен `125°`. Найди другой.
4. Один из смежных углов на `64°` больше другого. Найди меньший угол.
5. Вертикальный угол равен `68°`. Найди угол, вертикальный ему.
6. В треугольнике два угла равны `45°` и `70°`. Найди третий угол.
7. В треугольнике один угол равен `90°`, другой `35°`. Найди третий.
8. Найди угол при вершине равнобедренного треугольника, если угол при основании равен `50°`.
9. В равнобедренном треугольнике угол при вершине равен `40°`. Найди углы при основании.
10. Периметр равнобедренного треугольника равен `32` см, боковая сторона `10` см. Найди основание.
11. Периметр равнобедренного треугольника равен `48` см, основание `18` см. Найди боковую сторону.
12. Основание равнобедренного треугольника на `4` см меньше боковой стороны. Периметр `41` см. Найди стороны.
13. Внешний угол треугольника равен `120°`, один из удаленных внутренних углов `50°`. Найди второй удаленный внутренний угол.
14. В треугольнике `ABC` известно, что `∠A = 36°`, `∠B = 54°`. Укажи верное неравенство между сторонами.
15. Угол при основании равнобедренного треугольника в `2` раза больше угла при вершине. Найди все углы.
16. В треугольнике два угла относятся как `2:3`, а третий равен `40°`. Найди остальные углы.
17. Найди периметр треугольника со сторонами `7` см, `9` см и `12` см.
18. Основание равнобедренного треугольника равно `14` см, а боковая сторона на `3` см больше основания. Найди периметр.
19. Найди третий угол треугольника, если два других равны `58°` и `62°`.
20. Один из смежных углов в `4` раза больше другого. Найди оба угла.
